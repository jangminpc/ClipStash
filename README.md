# ClipStash

<img src="res/icon-preview.png" width="64" align="right" alt="ClipStash 아이콘">

**Windows용 가볍고 빠른 클립보드 기록 관리자.** Rust 로 Win32 API 를 직접 써서 만들었고,
실행 파일 하나(약 700KB)에 설치 없이 돌아갑니다.

복사(Ctrl+C)한 텍스트, 이미지, 파일을 자동으로 모아 두었다가 **Alt+C** 로
목록을 띄워 골라 붙여넣을 수 있습니다.

---

## 주요 기능

| | |
|---|---|
| 📋 **클립보드 기록** | 텍스트, 이미지, 탐색기에서 복사한 파일을 자동 기록. 같은 내용은 중복 없이 맨 위로 올라옴 |
| ⌨️ **Alt+C 팝업** | 아무 프로그램에서나 Alt+C(원하면 "Ctrl+C 빠르게 두 번"도 켤 수 있음) → 입력 커서(또는 마우스) 옆에 목록이 뜨고, 고르면 **원래 창에 바로 붙여넣기** |
| 🧩 **여러 개 한 번에 붙여넣기** | Space(또는 Ctrl+클릭, Shift+↑↓)로 여러 항목을 고르고 Enter → **복사한 순서대로 이어 붙여** 한 번에 붙여넣기. 사이에 넣을 글자(줄바꿈, 쉼표 등)는 설정 가능 |
| 🔢 **순차 붙여넣기** | 여러 번 복사해 두고 **Ctrl+V 를 누를 때마다 복사한 순서대로 하나씩** 붙여넣기. 양식 칸을 차례로 채울 때 편함. 팝업에서 고른 항목들로 시작할 수도 있음(Q) |
| 📸 **화면 캡처** | **Ctrl+Alt+C** → 마우스로 영역을 드래그하면 바로 기록에 들어가고 클립보드에도 복사. 그냥 클릭하면 그 모니터 전체 |
| 🔍 **이미지 크게 보기** | 목록의 썸네일을 클릭(또는 V)하면 크게 보여 줌 |
| 🔤 **글자 추출(OCR)** | 이미지 항목에서 O → Windows 내장 OCR 로 글자를 뽑아 텍스트로 복사(한국어 지원). 트레이 메뉴의 "화면 캡처해서 글자 추출" 로 한 번에 |
| 🗂️ **프로그램별 보기** | 어느 프로그램에서 복사했는지 기록. 팝업 오른쪽 위(또는 A)에서 프로그램을 고르면 그 프로그램 것만 표시 |
| ✏️ **고쳐서 붙여넣기** | F2 → 내용을 고친 뒤 Ctrl+Enter 로 붙여넣기(고친 글은 기록에도 남음). 템플릿도 펼친 결과를 고칠 수 있음 |
| 💬 **카카오톡 나에게 보내기** | 고른 항목을 K 한 번으로 내 카카오톡 "나와의 채팅"에 보내서 휴대폰에서 바로 사용(처음 한 번 설정 필요, 아래 설명) |
| 💾 **백업과 PC 간 동기화** | 기록·템플릿·이미지를 파일 하나로 내보내기/가져오기. OneDrive 같은 폴더를 지정하면 여러 PC 의 기록을 자동으로 맞춤 |
| 🎨 **심플한 반투명 팝업** | 번호 붙은 목록만 있는 깔끔한 디자인, **이미지는 작은 썸네일로 표시**, 다크/라이트 테마, 투명도 조절, Windows 11 둥근 모서리. 미리보기는 F3 으로 필요할 때만 |
| ⭐ **고정(즐겨찾기)** | 자주 쓰는 항목은 Ctrl+P 로 고정. 고정한 항목은 개수 제한에 걸려도 지워지지 않음 |
| 📝 **템플릿(상용구)** | 날짜·시간·요일, 지금 클립보드 내용 `{clipboard}`, 붙여넣은 뒤 커서 위치 `{cursor}` 같은 자리표시자 지원 |
| ✂️ **서식 없이 / 바꿔서 붙여넣기** | Shift+Enter = 텍스트만. 우클릭 → 대문자·소문자·공백 정리·한 줄로 합치기·빈 줄 제거·인용(`> `) |
| 🖼️ **미리보기** | 선택한 항목의 전체 텍스트, 이미지 썸네일, 파일 목록, 복사한 프로그램과 글자 수 표시 |
| 🔒 **민감한 앱 제외** | 비밀번호 관리자(KeePass, 1Password, Bitwarden 등)에서 복사한 내용은 기록 안 함. 앱이 "기록 금지" 표시를 붙인 복사도 자동으로 무시 |
| 🧭 **트레이 아이콘** | 화면 캡처, 순차 붙여넣기, 일시정지, Windows 시작 시 자동 실행, 백업, 설정 열기, 기록 지우기 |
| 💾 **자동 저장** | 기록은 껐다 켜도 남음. 저장 도중 꺼져도 파일이 깨지지 않게 안전하게 저장 |
| 🧳 **휴대용 모드** | exe 옆에 `data` 폴더를 만들면 그 안에 모든 데이터를 저장(USB 에 넣고 다니기) |
| 🖥️ **고해상도 모니터** | 모니터별 DPI 대응(PerMonitorV2). 4K/노트북 배율에서도 선명 |

## 설치와 실행

### 바로 받기
GitHub 의 **Actions** 탭 → 가장 최근 성공한 **CI** 실행 → 아래 **Artifacts** 에서
`clipstash-windows-x64` 를 받아 압축을 풀고 `clipstash.exe` 를 실행하세요.
창은 뜨지 않고 작업 표시줄 오른쪽 아래(트레이)에 아이콘이 생깁니다.

> 처음 실행할 때 Windows SmartScreen 이 "알 수 없는 게시자" 경고를 띄울 수 있습니다.
> 서명하지 않은 프로그램이라 그렇습니다. **추가 정보 → 실행** 을 누르면 됩니다.

### 직접 빌드하기 (Windows)
1. [Rust 설치](https://rustup.rs) (설치 중 나오는 Visual Studio C++ Build Tools 도 함께 설치)
2. 이 저장소를 받고 폴더에서:
   ```powershell
   cargo build --release
   ```
3. `target\release\clipstash.exe` 가 만들어집니다.

### Linux/macOS 에서 Windows 용으로 크로스 빌드
```bash
rustup target add x86_64-pc-windows-gnu
sudo apt install gcc-mingw-w64-x86-64      # macOS: brew install mingw-w64
cargo build --release --target x86_64-pc-windows-gnu
```

## 사용법

1. ClipStash 를 켜 두고 평소처럼 복사(Ctrl+C)합니다.
2. 붙여넣고 싶은 곳에서 **Alt+C** → 목록에서 고르고 **Enter**.

> 단축키는 설정의 `hotkey` 로 바꿀 수 있습니다. `double_copy_ms = 400` 으로 두면
> **Ctrl+C 를 빠르게 두 번** 눌러도 팝업이 뜹니다(한 번은 평소처럼 복사, Ctrl+C 는 가로채지 않음).

### 팝업 단축키

| 키 | 동작 |
|---|---|
| ↑ ↓ / PgUp PgDn / Ctrl+Home End | 항목 이동 |
| **Enter** / 더블클릭 | 붙여넣기 |
| **Shift+Enter** | 서식 없이 텍스트만 붙여넣기 |
| **Space** / Insert / Ctrl+클릭 | 여러 개 선택에 넣기·빼기(고른 항목에 ①②③ 표시) |
| **Shift+↑ ↓** | 지나가는 항목을 차례로 여러 개 선택 |
| Enter (여러 개 골랐을 때) | 고른 항목을 **복사한 순서대로** 이어 붙여 한 번에 붙여넣기 |
| **F2** / E | 고쳐서 붙여넣기(편집 칸에서 Ctrl+Enter = 붙여넣기, Esc = 취소) |
| F3 | 미리보기 칸 켜기/끄기 (여러 개 골랐으면 합쳐질 결과를 보여줌) |
| F4 / A | 프로그램 고르기(그 프로그램에서 복사한 것만 보기) |
| **Q** | 순차 붙여넣기 켜기/끄기. 여러 개 골라 둔 상태면 **고른 순서대로** 대기열을 만들고 닫힘 |
| V / 썸네일 클릭 | 이미지 크게 보기(아무 키나 클릭으로 닫힘) |
| O | 이미지에서 글자 추출(OCR) → 새 텍스트 항목 + 클립보드 |
| K | 카카오톡 나에게 보내기(여러 개 골랐으면 이어 붙여서) |
| **1 … 9, 0** | 1~10번째 항목 바로 붙여넣기 (Shift 와 함께 = 텍스트만) |
| **Tab** / Shift+Tab | 기록 → 고정 → 템플릿 탭 전환 |
| Ctrl+P | 고정 / 고정 해제 |
| Del | 항목 삭제 |
| Ctrl+T | 선택한 항목을 템플릿으로 저장 |
| Ctrl+C | 붙여넣지 않고 클립보드에 복사만 |
| Ctrl+E | 설정 파일 열기 |
| 우클릭 / 메뉴 키 / Shift+F10 | 더 보기 메뉴 (바꿔서 붙여넣기 등) |
| Esc | 여러 개 선택 해제 → 닫기 |

### 순차 붙여넣기

1. 트레이 메뉴 → **순차 붙여넣기** 를 켜거나, 팝업에서 **Q**.
2. 넣을 값들을 차례로 복사합니다(예: 이름 → 전화번호 → 주소).
3. 붙여넣을 곳에서 **Ctrl+V** 를 누를 때마다 복사한 순서대로 하나씩 들어갑니다.
   남은 개수는 트레이 아이콘 위에 마우스를 올리면 보입니다. 끄면 Ctrl+V 가 다시 평소처럼 동작합니다.

이미 기록에 있는 항목으로 하려면 팝업에서 Space 로 순서대로 고른 뒤 **Q** — 다 붙여넣으면 저절로 꺼집니다.

### 화면 캡처와 글자 추출

- **Ctrl+Alt+C**(설정 `capture_hotkey`) → 화면이 어두워지면 드래그로 영역 선택, 그냥 클릭 = 모니터 전체, Esc = 취소.
  캡처한 그림은 기록에 들어가고 클립보드에도 복사되어 바로 Ctrl+V 할 수 있습니다.
- 이미지 항목에서 **O** 를 누르면 글자를 뽑아 새 텍스트 항목으로 넣고 클립보드에 복사합니다.
  Windows 에 들어 있는 OCR 을 쓰므로 인터넷이 필요 없습니다. 한국어가 안 되면
  **설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션** 에서 "광학 문자 인식"을 설치하세요.

### 카카오톡으로 보내기 (처음 한 번 설정)

카카오가 공식으로 제공하는 "나에게 보내기" API 를 씁니다. 카카오 정책상 프로그램마다 개발자 앱 등록이 필요해서,
처음 한 번만 아래를 해 주셔야 합니다(무료, 5분 정도).

1. [developers.kakao.com](https://developers.kakao.com) 에 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
   (앱 이름은 아무거나, 예: "내 ClipStash").
2. **앱 키** 에서 **REST API 키** 를 복사해 둡니다.
3. **카카오 로그인** 메뉴에서 **활성화 설정 ON**, **Redirect URI** 에 `http://localhost:8765` 를 등록합니다.
4. **카카오 로그인 → 동의항목** 에서 **카카오톡 메시지 전송(talk_message)** 을 "선택 동의"로 켭니다.
5. ClipStash 설정 파일(Ctrl+E)의 `kakao_rest_api_key = "..."` 에 2번의 키를 넣고 저장합니다.
   (앱 보안 설정에서 Client Secret 을 켰다면 `kakao_client_secret` 에도 넣기)
6. 트레이 메뉴 → **카카오톡 나에게 보내기 연결…** → 브라우저에서 로그인하고 동의하면 끝.

그 뒤로는 팝업에서 항목을 고르고 **K** 를 누르면 카카오톡 "나와의 채팅"에 도착합니다.
- 카카오 메시지 한 개는 200자까지라, 긴 글은 여러 개(최대 10개)로 나눠 보냅니다.
- 이미지는 보낼 수 없습니다(먼저 O 로 글자를 뽑아서 보내 보세요).
- 로그인은 약 두 달 유지되고 그 사이엔 자동으로 갱신됩니다. 만료되면 다시 연결하면 됩니다.
- 로그인 정보(토큰)는 데이터 폴더의 `kakao_token.json` 에 저장됩니다. 트레이 메뉴 **카카오톡 연결 해제** 로 지울 수 있습니다.

### 백업과 다른 PC 와 동기화

- 트레이 메뉴 → **기록 백업 파일로 내보내기…** : 기록(이미지 포함)과 템플릿을 `.json` 파일 하나로 저장.
- 트레이 메뉴 → **백업 파일에서 가져오기…** : 이미 있는 항목은 건너뛰고 새 항목과 새 템플릿만 더합니다.
- **자동 동기화**: 설정에 `sync_folder = 'C:\Users\내이름\OneDrive\ClipStash'` 처럼 OneDrive·Dropbox·NAS 폴더를
  적으면, PC 마다 `ClipStash-PC이름.json` 을 그 폴더에 쓰고 1분마다(그리고 팝업을 열 때) 다른 PC 의 기록을 합칩니다.
  한 PC 에서 지운 항목은 다른 PC 에서도 지워집니다. 템플릿은 설정 파일에 있으므로 백업 파일로 옮기세요.

트레이 아이콘을 **왼쪽 클릭**하면 팝업이 마우스 위치에 뜹니다(이때는 붙여넣지 않고 클립보드에 넣기만 합니다).
**오른쪽 클릭**하면 메뉴가 나옵니다.

## 설정

트레이 메뉴 → **설정 파일 열기** (또는 팝업에서 Ctrl+E). 메모장으로 `config.toml` 이 열립니다.
파일에 항목마다 한국어 설명이 달려 있고, 저장하면 다음에 팝업을 열 때 자동으로 적용됩니다.

주요 항목:

```toml
hotkey = "Alt+C"               # 팝업 단축키. 예: "Ctrl+Shift+V", "F9", 끄려면 ""
capture_hotkey = "Ctrl+Alt+C"  # 화면 캡처 단축키, 끄려면 ""
double_copy_ms = 0             # 400 등으로 두면 Ctrl+C 두 번으로도 열기, 0 이면 끔
max_items = 300                # 보관 개수(고정 항목 제외)
capture_images = true          # 이미지도 기록
paste_after_select = true      # 고르면 바로 붙여넣기(false 면 복사만)
plain_text_by_default = false  # 항상 서식 없이 붙여넣기
popup_position = "caret"       # "caret" | "mouse" | "center"
theme = "dark"                 # "dark" | "light"
popup_opacity = 94             # 불투명도 %(50~100), 낮을수록 뒤가 비침
show_preview = false           # 미리보기 칸을 처음부터 보이기(F3 으로 전환)
merge_separator = "\n"         # 여러 개 붙여넣을 때 사이에 넣을 글자
excluded_apps = ["keepass.exe", "1password.exe", "bitwarden.exe"]
sync_folder = ""               # OneDrive 등 동기화 폴더(비우면 끔)
kakao_rest_api_key = ""        # 카카오톡 보내기용 REST API 키(위 설명 참고)

[[templates]]
name = "메일 맺음말"
group = "업무"
text = '''
{cursor}

감사합니다.
'''
```

### 템플릿 자리표시자

| 쓰기 | 결과 예 |
|---|---|
| `{date}` · `{time}` · `{datetime}` | 2026-11-24 · 15:35 · 2026-11-24 15:35 |
| `{date:yyyy년 M월 d일 (E)}` | 2026년 11월 24일 (화) |
| `{time:HH시 mm분}` | 15시 35분 |
| `{weekday}` | 화 |
| `{clipboard}` | 지금 클립보드에 있는 텍스트 |
| `{cursor}` | 붙여넣은 뒤 커서가 이 자리로 이동 |
| `{{` `}}` | 중괄호 문자 그대로 |

형식 문자: `yyyy` `yy` `MM` `M` `dd` `d` `HH` `H` `mm` `ss` `E`(요일)

## 데이터와 개인정보

- 데이터 위치: `%APPDATA%\ClipStash\` (휴대용 모드면 exe 옆 `data\`)
  - `config.toml` 설정 · `history.json` 기록 · `images\` 이미지 · `kakao_token.json` 카카오 로그인(연결했을 때만)
- **데이터는 내 컴퓨터에만 저장됩니다.** 인터넷은 카카오톡으로 보낼 때(고른 글만 카카오 서버로)만 씁니다.
  동기화 폴더를 지정하면 그 폴더에 기록 사본을 쓰므로, OneDrive 등에 올라간다는 점을 알아 두세요.
- `history.json` 은 암호화되지 않은 일반 파일입니다. 공용 컴퓨터라면 트레이 메뉴의
  **일시정지** 나 **기록 모두 지우기** 를 활용하세요.
- 다음 경우는 기록하지 않습니다:
  - `excluded_apps` 에 있는 프로그램에서 복사한 것
  - 복사한 프로그램이 "클립보드 기록 금지" 표시(`ExcludeClipboardContentFromMonitorProcessing`,
    `CanIncludeInClipboardHistory = 0` 등)를 붙인 것 — 대부분의 비밀번호 관리자가 이렇게 합니다
  - 일시정지 중일 때

## 테스트 상태 (중요)

이 프로그램은 Linux 클라우드 환경에서 만들어졌습니다. 확인된 것과 아직 확인하지 못한 것은 이렇습니다.

**확인됨**
- 핵심 로직(기록·중복 처리·고정·템플릿·텍스트 변환·설정 파일·저장/복구·BMP 변환·단축키 해석·
  백업 파일 형식·동기화 합치기와 지운 항목 처리·Base64·카카오 토큰/메시지 만들기·로그인 응답 해석)
  단위 테스트 45개 통과 (`cargo test --lib`)
- Windows 용 실행 파일 크로스 컴파일 성공, clippy 경고 없음
- GitHub Actions 의 실제 Windows 환경에서: 빌드, 테스트, 실행 후 텍스트를 복사하면 `history.json` 에
  기록되는지, 중복 실행 방지가 되는지 자동 확인 (`.github/workflows/ci.yml`)
- 같은 환경에서 참고용 점검: 그림에서 영어 글자 추출(OCR), 카카오 서버로 HTTPS 요청이 오가는지

**실제 Windows 화면에서 아직 확인하지 못함** — 직접 써 보시고 이상하면 알려주세요
- 팝업 창의 모양(글꼴, 간격, 색, 반투명, 둥근 모서리), 배율 125%/150% 모니터에서의 크기
- 여러 개 골라 한 번에 붙여넣기, 목록의 이미지 썸네일, 숫자 키 바로 붙여넣기, Ctrl+C 두 번 감지
- Ctrl+C 두 번 / 단축키로 팝업 → Enter 로 원래 창에 붙여넣기가 모든 프로그램에서 잘 되는지
  (특히 관리자 권한으로 실행된 프로그램에는 Windows 보안 정책상 붙여넣기 키를 보낼 수 없습니다)
- 입력 커서 옆에 팝업 띄우기: 메모장 같은 기본 프로그램은 되지만, 크롬·VS Code 등은 커서 위치를
  알려주지 않아 마우스 위치에 뜹니다
- 이미지 미리보기와 이미지 붙여넣기, 파일 복사/붙여넣기
- 트레이 아이콘, 풍선 알림, Windows 시작 시 자동 실행
- 순차 붙여넣기(Ctrl+V 가로채기)가 여러 프로그램에서 잘 되는지
- 화면 캡처 창(여러 모니터·배율이 다른 모니터), 이미지 크게 보기 창, 편집 칸(한글 입력)
- 한국어 OCR 정확도, 카카오 로그인과 보내기 전체 흐름(제 쪽에는 카카오 앱 키가 없어 실제로 보내 보지 못했습니다)
- 동기화 폴더를 두 PC 에서 함께 쓰는 경우

## 코드 구조

```
src/
  lib.rs          핵심 로직(운영체제와 무관, Linux 에서도 테스트 가능)
    history.rs    기록 목록: 추가·중복·고정·개수 제한·검색
    search.rs     검색 + 한글 초성 검색(지금 팝업에서는 쓰지 않음)
    template.rs   템플릿 자리표시자 치환
    transform.rs  붙여넣기 전 텍스트 변환
    config.rs     설정 파일(기본값과 설명 포함)
    storage.rs    저장/불러오기(안전한 쓰기, 손상 복구)
    hotkey.rs     "Alt+C" → Windows 키 코드, Ctrl+C 두 번 감지
    bmp.rs        클립보드 이미지(DIB) ↔ BMP 파일, 캡처 픽셀 → DIB
    backup.rs     백업/동기화 파일 형식
    b64.rs        Base64(백업 파일 속 이미지)
    kakao.rs      카카오 로그인·토큰·메시지 만들기
  main.rs
  win/            Windows 전용
    mod.rs        메인: 클립보드 감시, 전역 단축키, 트레이, 붙여넣기 흐름
    popup.rs      팝업 창(탭·번호 목록·이미지 썸네일·미리보기·우클릭 메뉴)
    clip.rs       클립보드 읽기/쓰기(텍스트·HTML·이미지·파일)
    paste.rs      원래 창으로 돌아가 Ctrl+V 보내기(순차 붙여넣기 포함)
    capture.rs    화면 영역 캡처 창
    ocr.rs        Windows.Media.Ocr 로 글자 추출
    kakao.rs      카카오 로그인(localhost 로 돌아오는 주소 받기)과 보내기
    net.rs        WinHTTP 로 HTTPS 요청
    backup.rs     백업 내보내기/가져오기, 동기화 폴더
    worker.rs     오래 걸리는 일을 다른 스레드에서
    util.rs       자잘한 도우미(경로, 프로세스 이름, 자동 실행 등)
res/              아이콘, 매니페스트(DPI·공용 컨트롤), 버전 정보
tools/make_icon.py 아이콘 그리는 스크립트
```
